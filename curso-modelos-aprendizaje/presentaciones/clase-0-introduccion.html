¿Qué es el Machine Learning?

💻 Programación tradicional

Le damos a la máquina reglas + datos y ella nos devuelve respuestas.

reglas + datos  →  respuestas

🤖 Machine Learning

Le damos datos + respuestas y la máquina descubre las reglas (el modelo).

datos + respuestas  →  reglas (modelo)
Idea claveEn ML no programamos las reglas a mano: el modelo las aprende a partir de los datos.

Nuestro primer dataset: Iris 🌸

Iris es un conjunto de datos clásico:

  • Medidas de 150 flores.
  • De 3 especies distintas.
  • Viene incluido en scikit-learn: no hay que descargar nada.
Cómo se carga load_iris(as_frame=True) lo entrega directamente como una tabla de pandas, lista para explorar. 
from sklearn.datasets import load_iris

iris = load_iris(as_frame=True)   # lo entrega como tabla de pandas
df = iris.frame                   # la tabla completa (features + objetivo)

# Renombramos la columna objetivo a algo legible
df["especie"] = iris.target_names[iris.target]

df.head()   # muestra las primeras 5 filas

Primera visualización

Una imagen dice más que mil filas. Con seaborn vemos cómo se separan las especies según el largo y ancho del pétalo.

plt.figure(figsize=(7, 5))
sns.scatterplot(
    data=df,
    x="petal length (cm)",
    y="petal width (cm)",
    hue="especie",     # color por especie
    s=70,
)
plt.title("Iris: las especies se separan por el tamaño del pétalo")
plt.show()
👀 ObservaLas tres especies forman grupos bastante separados. Por eso un modelo podrá aprender a distinguirlas.

Bonus: ver todas las combinaciones

Con una sola línea, seaborn compara todas las variables entre sí y colorea por especie.

sns.pairplot(df, hue="especie", height=1.8)
plt.show()
Para qué sirveEl pairplot nos deja ver de un vistazo qué pares de medidas separan mejor las especies. Es una gran herramienta de exploración.
