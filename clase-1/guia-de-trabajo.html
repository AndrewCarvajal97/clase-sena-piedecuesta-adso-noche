1. IA vs Machine Learning vs Deep Learning

Estos tres términos se confunden todo el tiempo. La mejor forma de entenderlos es imaginarlos como muñecas rusas: uno vive dentro del otro.

  • Inteligencia Artificial (IA): es el término más amplio. Cubre cualquier técnica para que una máquina imite comportamiento que llamaríamos "inteligente" (jugar ajedrez, reconocer una cara, traducir un texto).
  • Machine Learning (ML): una rama de la IA en la que la máquina aprende de datos, sin que le programemos cada regla a mano.
  • Deep Learning: un tipo de ML que usa redes neuronales profundas. Aquí viven los modelos modernos como los LLMs (ChatGPT, Gemini).

La gran diferencia: programación tradicional vs ML

En la programación de toda la vida, el humano escribe las reglas. En Machine Learning, la máquina descubre las reglas sola a partir de ejemplos.

Programación tradicionalMachine Learning
Le damos…Reglas + datosDatos + respuestas
Obtenemos…RespuestasLas reglas (el modelo)
Ejemplo"Si el correo dice 'gratis' → spam"Le muestro 10.000 correos marcados como spam/no-spam y el modelo descubre solo qué es spam
Idea centralEn ML no escribimos las reglas: le mostramos ejemplos a la máquina y ella infiere el patrón. Ese patrón aprendido se llama modelo.

2. ¿Cómo aprende una máquina?

Para entender el resto del curso necesitas dominar este vocabulario. Lo usaremos siempre.

  • Dato / Dataset: los ejemplos con los que aprende (por ejemplo, una tabla de casas).
  • Feature (característica): cada columna de entrada (tamaño, número de cuartos).
  • Label / Etiqueta (target): la respuesta correcta (el precio de la casa).
  • Modelo: la "fórmula" aprendida que relaciona las features con el label.
  • Entrenamiento: el proceso de ajustar el modelo con los datos.
  • Predicción / Inferencia: usar el modelo ya entrenado con datos nuevos.

Un ejemplo concreto: el precio de las casas

Tamaño (m²)# CuartosBarrio→ Precio (label)
803Centro$200M
1204Norte$350M
602Sur$150M
1003Norte¿? ← el modelo predice

Las tres primeras columnas son las features; el precio es el label. El modelo estudia las filas que sí tienen precio para aprender la relación, y así puede estimar el precio de la última fila.

El aprendizaje es prueba y error medido

Una máquina no "entiende" como nosotros. Aprende repitiendo un ciclo muy simple:

  1. El modelo hace una predicción (al principio, casi al azar).
  2. Comparamos con la respuesta real y calculamos el error (la función de pérdida o loss).
  3. Ajustamos el modelo un poquito para que el error sea menor.
  4. Repetimos miles de veces. Cada vuelta completa se llama época (epoch).
Sin magiaAprender = minimizar el error ajustando parámetros. Es optimización matemática. En Deep Learning se hace con una técnica llamada gradiente descendente, que veremos como intuición.

Los dos enemigos del aprendizaje

Overfitting (sobreajuste) El modelo memoriza los ejemplos en lugar de aprender el patrón. Le va muy bien en el examen que ya vio, pero mal en preguntas nuevas. Es como un estudiante que se aprende las respuestas de memoria pero no entiende el tema.
Underfitting (subajuste) El modelo es demasiado simple y no capta el patrón. Se equivoca incluso con los datos que ya conoce. Es como intentar explicar algo complejo con una sola regla.
El objetivoUn buen modelo generaliza: aprende el patrón real, no las respuestas de memoria, para acertar con datos que nunca ha visto.

3. Los cinco tipos de aprendizaje

Esta es la parte central de la clase. La pregunta clave que los diferencia es: ¿los datos traen la respuesta correcta?

3.1 Aprendizaje supervisado 🏷️

Aprende con datos etiquetados: cada ejemplo trae su respuesta correcta. Es como un estudiante con un profesor que le corrige cada ejercicio.

  • Clasificación: predecir una categoría (spam / no spam, perro / gato).
  • Regresión: predecir un número (precio, temperatura).
  • Ejemplos reales: detección de spam, diagnóstico por imágenes médicas, predicción de ventas, reconocimiento facial.
Su límiteNecesita muchos datos etiquetados, y etiquetar a mano es costoso y lento.

3.2 Aprendizaje no supervisado 🔍

Aprende con datos SIN etiquetas. Nadie le dice la respuesta; el modelo descubre por sí mismo la estructura oculta de los datos.

  • Clustering (agrupamiento): juntar cosas parecidas, por ejemplo segmentar clientes.
  • Reducción de dimensionalidad: simplificar datos muy complejos.
  • Detección de anomalías: encontrar lo "raro", como un fraude bancario.
AnalogíaTe dan una caja de fichas de LEGO revueltas y las organizas por color y forma sin que nadie te diga cuáles son las categorías. Tú mismo descubres los grupos.

3.3 Aprendizaje por refuerzo 🎮

Un agente aprende actuando en un entorno y recibiendo recompensas o castigos. No hay respuestas dadas de antemano: aprende de las consecuencias de sus acciones.

El ciclo es: el agente observa el estado, toma una acción, el entorno le devuelve una recompensa y un nuevo estado, y así repite, buscando siempre maximizar la recompensa total.

AnalogíaEnseñar a un perro. No le explicas con palabras: premias lo bueno (galleta) y no premias lo malo. Con el tiempo aprende la conducta que le da más galletas.

Ejemplos reales: IAs que juegan ajedrez, Go o videojuegos; robots que aprenden a caminar; autos autónomos; y el famoso RLHF (aprendizaje por refuerzo con retroalimentación humana), que se usa para "educar" a los LLMs como ChatGPT y Gemini.

3.4 Aprendizaje semi-supervisado 🏷️+🔍

Es una mezcla: pocos datos etiquetados y muchos sin etiquetar. Es muy útil precisamente porque etiquetar es caro.

EjemploTienes 1.000.000 de fotos, pero solo etiquetaste 1.000. El modelo usa esas 1.000 para orientarse y aprovecha las 999.000 restantes para afinar el patrón.

Ejemplos reales: clasificación de páginas web, o análisis de imágenes médicas donde etiquetar requiere un especialista costoso.

3.5 Aprendizaje autosupervisado 🧩 (¡el de los LLMs!)

El modelo crea sus propias etiquetas a partir de los datos. No necesita humanos etiquetando. Es la base de los LLMs modernos.

En texto funciona así: se le tapa una palabra de una frase y el modelo debe predecir la palabra que falta.

"El gato se subió al ___"  →  el modelo aprende que
probablemente es "techo" o "árbol".

Como la respuesta correcta ya está en el propio texto, se pueden usar millones de documentos sin etiquetar a mano. Por eso los LLMs pudieron entrenarse con casi todo internet.

EjemplosGPT, Gemini, Cohere y BERT se pre-entrenan de esta forma.

4. Redes neuronales y Deep Learning

La neurona artificial

Inspirada (muy libremente) en las neuronas del cerebro, una neurona artificial hace cuatro cosas:

  1. Recibe varias entradas (números).
  2. Cada entrada tiene un peso que indica qué tan importante es.
  3. Suma todo y le aplica una función de activación que decide si "se enciende".
  4. Produce una salida.
entradas   pesos
 x1 ──w1──┐
 x2 ──w2──┼─►  (Σ suma) ─► [activación] ─► salida
 x3 ──w3──┘
Aprender= ajustar los pesos para que la salida se parezca cada vez más a la respuesta correcta.

De una neurona a una red profunda

Al conectar muchas neuronas en capas obtenemos una red neuronal. Cuando tiene muchas capas, hablamos de Deep Learning (aprendizaje profundo).

Entrada    Capa oculta 1   Capa oculta 2   Salida
  O ───────── O ─────────── O ─────────── O
  O ───────── O ─────────── O ───────────
  O ───────── O ─────────── O
        (cada línea = un peso que se ajusta)
  • Las primeras capas detectan cosas simples (bordes, letras).
  • Las capas profundas combinan eso en conceptos complejos (una cara, el significado de una frase).
🧠 Los LLMsSon redes neuronales profundas gigantescas (miles de millones de pesos, llamados parámetros) con una arquitectura especial llamada Transformer. La Clase 2 abre esta caja negra.
