IA vs ML vs Deep Learning

Piénsalos como muñecas rusas: uno vive dentro del otro.

  • IA: cualquier técnica para que una máquina imite comportamiento "inteligente".
  • ML: la máquina aprende de datos, sin reglas escritas a mano.
  • Deep Learning: ML con redes neuronales profundas. Aquí viven los LLMs.
┌─ INTELIGENCIA ARTIFICIAL ─────┐
│  imita lo "inteligente"       │
│  ┌─ MACHINE LEARNING ───────┐ │
│  │  aprende de datos        │ │
│  │  ┌─ DEEP LEARNING ─────┐ │ │
│  │  │  redes neuronales   │ │ │
│  │  │  (aquí los LLMs)    │ │ │
│  │  └─────────────────────┘ │ │
│  └──────────────────────────┘ │
└───────────────────────────────┘

Programación tradicional vs ML

Programación tradicionalMachine Learning
Le damos…Reglas + datosDatos + respuestas
Obtenemos…RespuestasLas reglas (el modelo)
Ejemplo"Si dice 'gratis' → spam"Le muestro 10.000 correos marcados y él descubre qué es spam
Idea centralEn ML no escribimos las reglas: le mostramos ejemplos y la máquina infiere el patrón. Ese patrón aprendido se llama modelo.

El vocabulario del curso

  • Dato / Dataset: los ejemplos con los que aprende.
  • Feature (característica): cada columna de entrada (tamaño, # cuartos).
  • Label / Etiqueta: la respuesta correcta (el precio).
  • Modelo: la "fórmula" aprendida que va de features → label.
  • Entrenamiento: ajustar el modelo con los datos.
  • Predicción / Inferencia: usar el modelo ya entrenado con datos nuevos.

FíjateLas features son las 3 primeras columnas; el label es el precio. El modelo aprende la relación entre ambos.

¿Cómo "aprende"?

Con prueba y error medido:

  1. El modelo hace una predicción (al principio, casi al azar).
  2. La comparamos con la respuesta real → calculamos el error (pérdida / loss).
  3. Ajustamos el modelo un poquito para reducir ese error.
  4. Repetimos miles de veces. Cada vuelta es una época (epoch).
Sin magiaAprender = minimizar el error ajustando parámetros. Es optimización matemática (en Deep Learning: gradiente descendente).

Los dos enemigos del aprendizaje

Overfitting (sobreajuste) El modelo memoriza los ejemplos en vez de aprender el patrón. Va muy bien en el examen que ya vio, pero mal en preguntas nuevas.
Underfitting (subajuste) El modelo es demasiado simple y no capta el patrón. Se equivoca hasta con los datos que ya conoce.
El equilibrioUn buen modelo generaliza: aprende el patrón, no las respuestas de memoria.

Los 5 tipos de aprendizaje

🧠

Supervisado · No supervisado · Por refuerzo · Semi-supervisado · Autosupervisado

La diferencia clave: ¿los datos traen la respuesta correcta?

1. Aprendizaje SUPERVISADO 🏷️

Aprende con datos etiquetados: cada ejemplo trae su respuesta. Como un estudiante con un profesor que le corrige.

Se usa para:

  • Clasificación → predecir una categoría (spam / no spam).
  • Regresión → predecir un número (precio, temperatura).
Ejemplos realesDetección de spam, diagnóstico por imágenes médicas, predicción de ventas, reconocimiento facial.
CostoRequiere muchos datos etiquetados a mano. Etiquetar es caro y lento.

2. Aprendizaje NO SUPERVISADO 🔍

Aprende con datos SIN etiquetas. Nadie le da la respuesta: el modelo descubre estructura oculta solo.

Se usa para:

  • Clustering → juntar cosas parecidas (segmentar clientes).
  • Reducción de dimensionalidad → simplificar datos.
  • Detección de anomalías → hallar lo raro (fraude).
AnalogíaTe dan fichas de LEGO revueltas y las organizas por color y forma sin que nadie te diga las categorías.

3. Aprendizaje POR REFUERZO 🎮

Un agente aprende actuando en un entorno y recibiendo recompensas o castigos. Aprende de las consecuencias.

Ciclo: observa el estado → toma una acción → recibe recompensa y un nuevo estado → repite, buscando maximizar la recompensa total.

Piezas: agente, entorno, acción, estado, recompensa.

AnalogíaEnseñar a un perro: premias lo bueno (galleta) y no lo malo. Con el tiempo aprende la conducta que maximiza galletas.
DatoEl RLHF (refuerzo con retroalimentación humana) se usa para "educar" a los LLMs como ChatGPT y Gemini.

4. Aprendizaje SEMI-SUPERVISADO 🏷️+🔍

Una mezcla: pocos datos etiquetados + muchos sin etiquetar. Muy útil porque etiquetar es caro.

EjemploTienes 1.000.000 de fotos, pero solo etiquetaste 1.000. El modelo usa esas 1.000 para orientarse y las 999.000 restantes para afinar el patrón.

Ejemplos reales

  • Clasificación de páginas web.
  • Análisis de imágenes médicas donde etiquetar exige un especialista.

5. Aprendizaje AUTOSUPERVISADO 🧩

El modelo crea sus propias etiquetas a partir de los datos. No necesita humanos etiquetando. Es la base de los LLMs.

Cómo funciona en textoSe le tapa una palabra y debe predecirla:
"El gato se subió al ___" → aprende que probablemente es "techo" o "árbol".

Como la respuesta ya está en el propio texto, se usan millones de documentos sin etiquetar. Por eso los LLMs pudieron entrenarse con casi todo internet.

EjemplosGPT, Gemini, Cohere, BERT — todos se pre-entrenan así.

La neurona artificial

Inspirada (muy libremente) en el cerebro. Una neurona:

  1. Recibe varias entradas (números).
  2. Cada entrada tiene un peso (su importancia).
  3. Suma todo y aplica una función de activación.
  4. Produce una salida.
entradas   pesos
 x1 ──w1──┐
 x2 ──w2──┼─► (Σ) ─► [activación] ─► salida
 x3 ──w3──┘
Aprender= ajustar los pesos para que la salida se parezca a la respuesta correcta.

De una neurona a una red profunda

Entrada   Oculta 1   Oculta 2  Salida
  O ────── O ─────── O ─────── O
  O ────── O ─────── O ───────
  O ────── O ─────── O
   (cada línea = un peso que se ajusta)

Muchas neuronas en capas forman una red neuronal. Con muchas capas → Deep Learning.

  • Primeras capas: cosas simples (bordes, letras).
  • Capas profundas: conceptos complejos (una cara, el sentido de una frase).
🧠 Los LLMsSon redes profundas gigantes (miles de millones de parámetros) con una arquitectura llamada Transformer. La Clase 2 abre esa caja negra.
